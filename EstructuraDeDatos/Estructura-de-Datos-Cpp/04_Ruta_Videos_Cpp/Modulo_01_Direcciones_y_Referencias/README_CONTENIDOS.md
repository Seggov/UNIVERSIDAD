# Módulo 01 — Direcciones y referencias

Estado: pendiente. Mira juntos **#45, #46 y #47** de la [playlist](https://www.youtube.com/playlist?list=PL5YuOOJ-FGGjjK8j50TkEcjCcZ8dRAiPy).

- #45: direcciones de memoria. `&variable` permite observar dónde está una variable.
- #46: paso por valor y por referencia. Un parámetro por valor recibe una copia; una referencia permite modificar la variable original.
- #47: parámetros constantes. `const int&` permite consultar el original sin modificarlo mediante ese parámetro.

Prerrequisitos: funciones, retorno, condiciones y operaciones aritméticas.

Al terminar debes poder distinguir `&` en una expresión de `&` en una declaración de referencia y predecir qué variables cambian después de una llamada.

No necesitas punteros declarados con `*`, new, struct ni clases para este ejercicio. El #48 es práctica opcional al cerrar el módulo.
