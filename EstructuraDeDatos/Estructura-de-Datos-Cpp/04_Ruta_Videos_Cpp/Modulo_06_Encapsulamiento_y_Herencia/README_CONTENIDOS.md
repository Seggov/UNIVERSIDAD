# Módulo 06 — Encapsulamiento y herencia

Estado: pendiente. Mira juntos **#61 y #62** de la [playlist](https://www.youtube.com/playlist?list=PL5YuOOJ-FGGjjK8j50TkEcjCcZ8dRAiPy).

- #61: getters, setters y acceso controlado a atributos privados.
- #62: herencia pública: una clase derivada reutiliza operaciones de una clase base.

Prerrequisitos: módulos 01–05. Copia tu solución del módulo 05 a este main.cpp y adáptala; no reemplaces la versión anterior.

Objetivo: proteger el saldo y agregar una cuenta con un bono sin repetir las operaciones comunes.

La base incluye la sintaxis CuentaBonificada(int saldoInicial, int bonoInicial) : Cuenta(saldoInicial). La parte Cuenta(...) llama al constructor de la clase base.

No se requieren virtual, override, clases abstractas, constructor de copia ni sobrecarga de operadores: se prepararán después para la evaluación final.
