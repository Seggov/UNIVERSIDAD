# UNIVERSIDAD · Repositorio General de Asignaturas (2026-2)

Respaldo centralizado de materiales de cátedra, laboratorios, talleres, código fuente y herramientas visuales de estudio.

## Estructura del Repositorio

- **`Portal_Estudio_Prueba2/`**: Portal web estático e interactivo de estudio bloque por bloque (`index.html`), con diagramas SVG, simuladores interactivos, guías de dibujo y enunciados oficiales.
- **`Plan_Estudio_Prueba2_Nov23_30.md`**: Cronograma detallado de estudio y distribución horaria para la Prueba 2.
- **`Arquitectura Computadores/`**: Presentaciones (Clases 1–9), guía de lectura activa, talleres en ensamblador/SimuProc y guía visual interactiva (`index.html`).
- **`EstructuraDeDatos/`**: Repositorio completo en C++ (`Estructura-de-Datos-Cpp`) con material teórico, ruta de módulos prácticos (Prueba 1 y Prueba 2) y Taller 2 Hospital (`Taller-2_Estructura`).
- **`Cibseguridad/`**: Laboratorios de red física, firewall/iptables, SOC, SIEM, arquitectura Zero Trust y auditoría ISO/IEC 27001 (`AustranetAuditoria`).
- **`CienciadeDatos/`**: Clases (01–09), ayudantías, glosarios, resúmenes y Laboratorio 2 de predicción de demanda en KNIME (`Taller 2/Ciencia-de-Datos-2`).
- **`ProyectoSistemasInteligentes/`**: Documentación y recursos del proyecto del curso.
