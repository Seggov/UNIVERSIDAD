1. Conexión Física: Tu PC al Rack

Capa 1

Cadena exacta de cables que permite que la señal salga de tu computador hacia el laboratorio:

[ Tu PC de Trabajo ] │ ▼ (1) Patch Cord (cable flexible RJ-45) [ Toma de Red en la Pared / Roseta ] │ ▼ (2) Cable UTP Cat 6 rígido (va por canaleta oculta) [ TRASERA DEL RACK: Punchado en Patch Panel ] │ ▼ (3) Salida frontal del Patch Panel [ FRONTAL DEL RACK: Patch Cord ] │ ▼ (4) Switch de Acceso (Capa 2) │ ▼ (5) Cable UTP de Enlace [ FIREWALL FÍSICO WATCHGUARD (Capa 3/4) ]
¿Por qué existe el Patch Panel? Para proteger el switch. El cableado de pared es rígido y no se debe doblar ni conectar/desconectar directamente; el patch panel recibe ese cable fijo y ofrece puertos frontales accesibles.

3. ¿Por qué nos conectamos a otro PC en el mismo Rack?

Capa 2 / ARP

Si PC 1 (192.168.1.10) se comunica con PC 2 (192.168.1.20) en el mismo switch:

[ PC A: 192.168.1.10 ] [ PC B: 192.168.1.20 ] │ ▲ ▼ (1) Pregunta ARP: │ (3) Entrega directa "¿Quién tiene la 1.20?" │ ┌─────────────────────────────────────────────────────────────┐ │ SWITCH DEL RACK (Capa 2) │ │ Tabla MAC: [Puerto 3: MAC de A] [Puerto 7: MAC de B] │ └─────────────────────────────────────────────────────────────┘
  • Misma Subred: Como la máscara es 255.255.255.0 (/24), ambos saben que están en la red local. No necesitan usar el Firewall.
  • Protocolo ARP: PC A pregunta por broadcast quién tiene la IP de destino. PC B responde con su dirección física MAC.
  • El Switch reenvía por hardware: Conecta el puerto eléctrico de A con el de B instantáneamente.

4. Mapa de IPs (IPEs) y sus Tipos

Capa 3

Una IP identifica a un equipo lógicamente. En el taller se usan IPs Privadas (RFC 1918):

Rango Privado Clase Uso en el Taller
10.0.0.0/8 Clase A Trusted: Red del Admin (10.0.1.x).
172.16.0.0/12 Clase B Redes intermedias y servidores.
192.168.0.0/16 Clase C Grupos: Grupo n usa 192.168.n.0/24.

Los 4 Roles dentro de una Subred (/24):

  • .0 (Ej. 192.168.1.0): IP de Red (identifica al grupo, no se asigna a PCs).
  • .1 (Ej. 192.168.1.1): Gateway / Firewall (la puerta hacia otras redes).
  • .2 a .254: IPs de Host (asignables a PCs, Kali, Windows, servidores).
  • .255: IP de Broadcast (envía el mensaje a todos a la vez).

5. Cómo Conectarse al Firewall Físico

Administración
  1. Conexión Física: Conecta tu PC al Puerto 1 del WatchGuard (Interfaz Trusted).
  2. Asignar IP fija a tu PC:
    IP: 10.0.1.2 | Máscara: 255.255.255.0 | Gateway: 10.0.1.1
  3. Abrir el navegador web: Entrar a la URL:
    https://10.0.1.1:8080
  4. Credenciales del Taller:
    Usuario: admin | Contraseña: readwrite
  5. Si el equipo no responde: Reiniciar en Modo Seguro manteniendo presionado el botón reset al encender.

6. Conectarse a Otras IPs: ¿Qué vemos?

Capa 4 / 7

Si la IP está en otra zona (ej. desde Trusted 10.0.1.2 hacia la DMZ 192.168.1.5):

El paquete viaja al Gateway (10.0.1.1). El firewall revisa sus políticas. Si está permitido, lo que ves en tu pantalla depende del puerto:

Puerto / Servicio ¿Qué vemos en la pantalla?
Puerto 80 / 443 (HTTP/S) La página web del servidor (DVWA, formulario, tienda).
Puerto 22 (SSH) Una terminal Linux remota (pantalla negra pidiendo login).
Puerto 23 (Telnet) Terminal remota insegura (credenciales en texto plano).
ICMP (Ping) Reply from 192.168.1.5: bytes=32 time=1ms
Escaneo Nmap Listado de qué puertos están abiertos (21, 22, 80, 3306).

7. ¿Qué podemos hacer con los Protocolos?

Reglas del Juego
TCP (Fiabilidad Absoluta):

Hace saludo en 3 vías (SYN, SYN-ACK, ACK). Si se pierde un paquete, se reenvía. Se usa para: Web (80/443), SSH (22), Base de datos MySQL (3306).

UDP (Velocidad Inmediata):

Sin conexión y sin reintentos. Se usa para resolución rápida de nombres (DNS puerto 53) y asignación automática de parámetros de red (DHCP 67/68).

ICMP (Diagnóstico):

Prueba si el medio físico y el equipo remoto están vivos mediante peticiones de eco (ping).

Resumen de Oro para el Caso de Mañana: Web en la DMZ, Base de Datos en la red Trusted. Tráfico DMZ -> Trusted = DROP. El Firewall siempre es la .1. La política final siempre es Deny All.
